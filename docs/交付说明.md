## 五、apply / undo 使用说明

```powershell
# 安装/更新语言包（幂等：先还原干净副本 → 备份 → 注入 → 重启应用）
# 需要管理员权限；本机 UAC 为"管理员不提示"，普通窗口里跑下面这行即可：
Start-Process 'C:\Program Files\PowerShell\7\pwsh.exe' -ArgumentList '-NoProfile','-ExecutionPolicy','Bypass','-File','F:\deep\_twindesk_i18n\apply.ps1' -Verb RunAs -Wait

# 只打补丁不启动应用：
... -File 'F:\deep\_twindesk_i18n\apply.ps1' -NoLaunch ...

# 一键还原英文（不动 backup 目录）：
Start-Process 'C:\Program Files\PowerShell\7\pwsh.exe' -ArgumentList '-NoProfile','-ExecutionPolicy','Bypass','-File','F:\deep\_twindesk_i18n\undo.ps1' -Verb RunAs -Wait
```

- 启动 TwinDesk 前务必清掉环境变量 `ELECTRON_RUN_AS_NODE`（继承自父进程时 Electron 会当 node 秒退）：`Remove-Item Env:ELECTRON_RUN_AS_NODE`。
- 改词条流程：编辑 `patch\zh-cn\zh-dict.js`（或往 `manual.json` 的 exact/patterns 增补，或加 `trans\batchN.json`）→ `node build.js` → 重新跑 apply.ps1 → 重启应用。
- 备份在 `F:\deep\_twindesk_i18n\backup\`（11 个 HTML + 2 个 main.js 的原始副本），undo.ps1 依赖它，请勿删除。
- 卸载 TwinDesk 或其升级后补丁会失效，重跑 apply.ps1 即可。
