## 三、如何自己重新编译

环境（都已备好，免安装，放在 `F:\deep\_twindesk_i18n`）：

| 组件 | 位置 |
|---|---|
| 源码 | `src/`（v2.4.0 tag，git 仓库） |
| JDK 21 | `android/tools/jdk-21.0.12.1+1` |
| Android SDK | `build/android-sdk`（platform `android-37.0`、build-tools `37.0.0`、platform-tools、licenses） |
| Gradle 9.8.1 发行包 | `build/gradle-9.8.1-bin.zip`（wrapper 已指向本地 file://） |
| 镜像配置 | `%USERPROFILE%\.gradle\init.gradle`（华为云 / 阿里云 Maven 镜像） |

编译命令：

```powershell
$env:JAVA_HOME = "F:\deep\_twindesk_i18n\android\tools\jdk-21.0.12.1+1"
$env:PATH = "$env:JAVA_HOME\bin;$env:PATH"
cd F:\deep\_twindesk_i18n\src\android
.\gradlew assembleStandardRelease
# 产物：app\build\outputs\apk\standard\release\app-standard-release.apk
```

- 项目原本用 `build-tools;36.0.0`，本地只有 37.0.0，已在 `app/build.gradle.kts` 固定
  `buildToolsVersion = "37.0.0"`（仅构建配置改动，不影响应用代码）。
- release 构建按项目原配置使用 **debug 密钥签名**（源码里就是这样设置的）。

## 四、汉化是怎么做的（源码级，不是 smali 补丁）

脚本在 `build/`，按顺序执行（都只改 Kotlin 字符串字面量）：

| 脚本 | 作用 | 替换量 |
|---|---|---|
| `patch_source.js` | 用 `android/trans_table.json`（582 条英→中）翻译 Kotlin 字面量 | 467 处 / 28 文件 |
| `patch_source3.js` | 连接后页面（屏幕/光标/文件/更多）+ 配对弹窗等整句与标签 | 70 处 |
| `patch_source4.js` | 补回 Tab 标签（概览/远程/剪贴板/声音等）+ 蓝牙说明模板 | 70 处 |
| `patch_source5.js` | 文件页最后 2 句（同一变量重复的模板修正） | 2 处 |

共约 **609 处**源码字符串汉化，全部是**展示文案**，没有改协议字段/JSON key/SQL/日志。
回退源码改动：`cd src && git checkout -- android/app/src/main/java`
